# ADR 0004: Draft-Market Source Selection

Date: 2026-10-10
Status: Fantrax selected for private personal use; live sync verified 2026-10-10. No second qualifying source identified.

## Context

The production `draft_market_data` table has 0 rows. The live database has 733 Yahoo player identities, 717 NBA players, 1,054 season-stat rows, and 658 draft metrics. Yahoo player-pool imports work, but the persisted live player payloads contain no ADP, draft rank, XRank, ownership, or percent-owned fields. The current Yahoo draft-analysis probe supplied no usable ADP; previous-season draft-history access returned 403.

The source must provide current NBA fantasy draft ADP, be usable at no charge for this private personal app, support automated retrieval through a documented interface, and provide sufficient identity fields for conservative matching. Rankings, ownership, XRank, and projections are not substitutes for ADP.

The source search also checked ESPN and Sleeper. ESPN has current fantasy editorial material and rankings but its applicable terms prohibit automated extraction absent express written permission. Sleeper's official documentation check did not establish an NBA ADP feed. Neither qualifies as an additional automated source on the evidence available.

## Decision

Use Fantrax's documented public NBA ADP endpoint for this private personal app. The sync issues two sequential GETs: current ADP and its documented player-ID crosswalk. It does not scrape pages, authenticate as another user, bypass restrictions, or use undocumented endpoints. It matches only on normalized full name, team, and position; free agents, mismatches, and non-unique candidates remain unresolved and are reported. `player_identity` is never modified.

The API supplies ADP only. It does not supply draft rank, XRank, draft frequency, sample size, or a source update timestamp; those fields remain null. Retrieval timestamp is saved locally. Data older than 48 hours is stale for survival. A failed request is logged without response bodies/secrets and recorded as a failed sync run; existing ADP rows are retained. This source is not redistributed. Obtain written permission before reusing the feed beyond private personal use.

At the source-selection milestone, v1 survival was a transparent, uncalibrated heuristic driven by current ADP, pick distance, league size, snake position, and recent positional runs. Request ADP overrides provider data. Stale/missing ADP returns unknown survival. The v1 50% Draft Now/Safe to Wait threshold was explicitly heuristic, not calibrated; v2 fallback-based action semantics supersede that threshold as documented in [ADR 0006](0006-draft-survival-and-wait-method.md). No historical evaluation dataset exists, so no calibration claim is made.

## Revisit Conditions

Revisit if Fantrax changes its API, terms, or personal-use access. For other deployment contexts, verify permission and license anew. Add any secondary provider only after the same checks and never treat rankings/ownership as ADP. At this ADR's date, the existing market tables still used the metadata bootstrap; v2 draft-state persistence is now migration-managed under [ADR 0005](0005-draft-state-persistence.md).
