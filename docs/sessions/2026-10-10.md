## Source Decision

Fantrax's documented `getAdp?sport=NBA` and `getPlayerIds?sport=NBA` endpoints returned current JSON without authentication. The first exposes ADP/name/ID/position; the crosswalk exposes Fantrax ID/name/team/position. Fantrax terms prohibit scraping and require use through published interfaces; this private personal app uses only documented APIs and does not redistribute. The source does not expose sample size, draft frequency, or source-updated timestamp. Hashtag HTML/terms, FantasyPros non-production free tier, RotoWire no-scraping terms, and the unlicensed GitHub prediction model remain rejected. See [ADR 0004](../adr/0004-draft-market-source-selection.md).

Follow-up source search checked current ESPN fantasy pages, Disney terms, Sleeper's official API docs/help, and GitHub searches for licensed ADP datasets. ESPN offers rankings/editorial draft content rather than a verified ADP feed and Disney terms prohibit automated extraction absent written permission. Sleeper documentation did not establish an NBA ADP feed (docs extraction failed; linked help returned 404). No additional qualifying free automated source was found; exact gap remains 399 identities absent from Fantrax plus 22 unresolved source records.

Existing v1 routes remain.
- Replaced the v1 wait-cost shortcut for scored candidates with expected utility of up to five scored alternatives at the next pick. Alternatives are utility-ranked; their survival estimates determine the probability each is the best available fallback under an explicit independence assumption. `expected_wait_cost = U_now - [P_survive * U_now + P_gone * E_fallback]` is signed. Missing required survival produces `insufficient_evidence`; confidence is low/unavailable and survival remains `heuristic_unvalidated`.
- Snapshots preserve session version/configuration, ordered picks, source/timestamp/evidence, drafted and available IDs, and the recommendation response. Historical outcomes and retrospective process scoring are not implemented.
