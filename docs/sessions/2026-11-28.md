## Phase 9 review (22 contract points)

All 22 points pass by code inspection; no defect was found, so no code changed.

- **Rule:** `supported = window_gain >= round(max(0, round(drop − replacement, 2)) × max(0, rest − window), 1)`. All
  values are 2-dp before subtraction, so the page's line reproduces the cost exactly. Rest-of-season and window games
  share the same start date and schedulable-status filter.
- **Scope:** the check runs only in weekly horizons, for a positive, explanation-consistent ADD + DROP whose
  production cost is compensated by a holding schedule claim. Rest of Season Outlook gets no replacement callback, and
  no-drop comparisons (ADD ONLY, IL moves) have no drop. Production-led pairs have no compensators; fit-led pairs have
  no holding schedule claim.
- **Decisions:** the gate sits after the explanation gate and before the sample gate. A blocked pair is PASS → HOLD /
  DO NOT ADD, or INSUFFICIENT EVIDENCE when a status is unverified; it is never WATCH. `PASS` is not actionable.
- **Optimizer:** `evaluate_pair` adds a permanent-drop blocker. `_decision_pair` scans drops by net to the first
  strong pair, and `_best_actionable` admits only ADD / STREAM / MUST ADD.
- **lower_cost_drop:** strictly lower 2-dp values only, so a chain of lookups always moves to cheaper drops and
  terminates.
- **Replacement level:** off the roster; `availability_actionable` (which excludes O/OFS/NA and other teams' players);
  resolved identity, fresh recent production, no status gap and a passing sample. Impact reads load the same full
  context.
- **Other surfaces:** Compare a Specific Drop, OTHER GOOD OPTIONS and the frontend render backend facts only, and every
  frontend surface fails closed on a model mismatch. Phases 6–8, heavy-read admission and PC-only behavior are
  untouched by the Phase 9 diff.
- **Scope precision (documented in project memory):** a pair compensated by both a fit gain and a holding schedule
  edge is in scope under the audit's exact rule. The gate does not credit the fit gain, so it errs toward HOLD.
- **Probes (qa-work only, not committed):** 15 probes in the running image passed. A fit-led pair is never checked. 12
  kinds of ineligible stronger player (O, OFS, NA, another team's roster, unverified or stale availability, unresolved
  identity, stale or missing production, blank or stale status, small sample) never set replacement level; an eligible
  one does.
